# PITFALLS — грабли, собранные на живых лендингах

Каждый пункт — реальная поломка, которая выглядела как «всё работает». Применять на шаге 6, при деплое и при проверке.

## Анимации и показ контента

1. **Библиотека анимаций может молча не сработать.** ESM-модуль с CDN грузится без ошибок, но `inView()` не срабатывает — элементы с `opacity:0` остаются невидимыми, страница выглядит пустой. Reveal-анимации делать на нативном `IntersectionObserver` и CSS-классах.
2. **Атрибут `hidden` перебивается `display:flex/grid`.** Элемент виден, хотя помечен скрытым. В reset всегда: `[hidden]{display:none!important}`.
3. **Прятать контент до анимации можно только когда JS точно работает.** Скрипт ставит класс `js` на `<html>`, CSS прячет через `html.js [data-reveal]`. Плюс страховочный таймер, который показывает всё нераскрытое.
4. **WebGL-фоны** (шейдеры с CDN) в статическом HTML работают, но нужен CSS-градиент как фолбэк и остановка `requestAnimationFrame` вне вьюпорта.

## Проверка после деплоя

5. **Проверять в живом браузере, а не по HTTP-кодам.** Четыре разные поломки отдавали 200 на всех адресах. 404 на ресурсах и ошибки JS видно только в консоли и на full-page скриншоте после прокрутки.
6. **Reveal-«дыры» видны только прокруткой.** Плавный скролл шагами, full-page скриншот, счёт раскрытых элементов.
7. **Headless-браузер не сужается меньше 500px.** Мобильный скриншот на 390px получится обрезанным. Мерить мобильную версию через iframe нужной ширины или в настоящем устройстве.
8. **Замена картинки = новое имя файла.** Если `/assets/*` отдаётся с кэшем на год, под старым именем пользователь увидит старую версию и даже запомненный 404.

## Формы и аналитика

9. **Канал приёма заявок обязан уметь жаловаться.** `fetch` в режиме `no-cors` плюс одинаковые ветки «успех/ошибка» прячут поломку месяцами. Проверять живой отправкой и смотреть, что заявка реально дошла.
10. **События GA4 проверять по телу запроса, а не по адресу.** POST-батч прячет `en=` из URL, и рабочее событие выглядит несработавшим.
11. **UTM-метки только на внешние переходы.** Внутри своего домена метка обрывает сессию и стирает настоящий источник. Внутренние переходы мерить событиями.

## Деплой

12. **Перед пушем проверить, что git-интеграция хостинга включена.** Репозиторий есть, коммит запушен, а сборка не запустилась, потому что проект к репо не привязан. Выглядит как «деплой долго идёт».
13. **Если интеграция есть — деплоить только через push**, а не из локальной папки: локальная копия бывает неполной, и картинки исчезают с сайта.
14. **Короткие редиректы занимают пути сайта.** Перед созданием раздела `/blog` или `/portfolio` проверить, нет ли уже такого редиректа в конфиге хостинга.
15. **Отчёт о правках должен читать тексты из живого кода**, а не из копии: копия расходится с продом молча.

## Тексты и код

16. **`\b` в регулярках JavaScript не работает с кириллицей.** `/\bпотому что\b/` ничего не находит и не падает. При переносе проверок из Python проверять первым делом.
17. **Скрипт-линтер текста должен щадить цитаты.** Примеры «как не надо», промты в `<pre>` и вопросы FAQ из JSON-LD трогать нельзя.
18. **Поисковая формулировка — в `<title>`, образный заголовок — в `<h1>`.** Иначе живой текст просто не находят по запросу.
19. **Шрифт с кириллицей проверять отдельно.** У части модных шрифтов в Google Fonts кириллицы нет; курсив синтезируется. Держать локальный файл.
