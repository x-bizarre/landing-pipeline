# Как вебинар соотносится с публичным пайплайном

В вебинаре показан исторический путь кейса BlackPixel в шести крупных шагах. Репозиторий превращает его в более безопасный и воспроизводимый процесс из семи шагов.

| Вебинар | Публичный пайплайн |
|---|---|
| 1. Синтетический кастдев | 1. Discovery + 3. Synthetic Custdev |
| 2. Парсинг живых отзывов | 2. Reviews Parser |
| 3. Артефакт-ТЗ | 4. Copy Brief |
| 4. Локализация | 7d. Multilingual |
| 5. GEO | 7a. SEO/GEO |
| 6. Сборка и деплой | 5. Design + 6. Landing + 7b–c Mobile/PageSpeed + Deploy |

В кейсе синтетика сначала дала направления, а живые обсуждения затем их подтвердили или опровергли. В публичной версии порядок намеренно строже: сначала собираются проверяемые отзывы, затем синтетика формулирует гипотезы и фиксирует их статус. Гипотезы нельзя выдавать за исследование, отзывы или social proof.

Дополнительные приёмы со слайда «Что ещё бесплатного» вынесены в `recipes/`: короткие UTM-ссылки и простой A/B-тест. Решение с девятью полями не является универсальным правилом; критерии выбора длины формы описаны отдельно.
