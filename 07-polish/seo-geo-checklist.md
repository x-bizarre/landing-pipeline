# SEO + GEO чек-лист для лендинга

GEO — Generative Engine Optimization: чтобы страницу находили, понимали и цитировали AI-поисковики (ChatGPT, Perplexity, Gemini, Google AI Overviews). SEO и GEO пересекаются, но требования разные. Чек-лист применяется на шаге 7a до деплоя и повторно после.

## 1. Базовое SEO (обязательно)

- [ ] `<title>` 55–60 символов, в нём поисковая формулировка запроса (а образный заголовок — в `<h1>`)
- [ ] `<meta name="description">` 150–160 символов с конкретной выгодой
- [ ] Один `<h1>`, отвечает на primary барьер из шага 3
- [ ] Логичная иерархия `h2`/`h3`, без пропуска уровней
- [ ] Canonical URL
- [ ] Open Graph и Twitter Card: `og:title`, `og:description`, `og:image` 1200×630 WebP
- [ ] `alt` у всех содержательных картинок, осмысленные имена файлов
- [ ] `robots.txt` и `sitemap.xml`
- [ ] Ключевые слова: 1 основной + 3–5 длинных хвостов, распределены по H1, первому абзацу, подзаголовкам

## 2. Структурированные данные (JSON-LD)

- [ ] `WebPage` / `Product` / `SoftwareApplication` / `Service` — по типу продукта
- [ ] `Organization` или `Person` с `sameAs` на соцсети и профили
- [ ] `FAQPage`, если на странице есть FAQ (вопросы дословно совпадают с видимым текстом)
- [ ] `BreadcrumbList` только если у страницы есть реальная навигационная цепочка
- [ ] `Review` + `AggregateRating` только при реальных отзывах
- [ ] `HowTo` только если есть видимая пошаговая инструкция; не обещать rich result
- [ ] Проверено в Rich Results Test и Schema Markup Validator

## 3. GEO-слой (видимость в AI-поиске)

- [ ] **Первый абзац — прямой ответ** на главный запрос, без разгона. AI-модели цитируют самодостаточные абзацы
- [ ] Каждая содержательная секция начинается с ясного самодостаточного утверждения без искусственного требования к числу слов
- [ ] Конкретные цифры с источником, даты, имена — вместо «многие компании»
- [ ] FAQ структурирован: вопрос как заголовок, ответ в 1–3 предложения сразу под ним
- [ ] `speakable` не добавлен на обычный лендинг: это ограниченный beta-сценарий, не универсальный GEO-сигнал
- [ ] Опциональный `llms.txt` помечен как экспериментальный навигационный файл; не выдавать его за подтверждённый фактор ранжирования или цитирования
- [ ] Нужные поисковые и AI-краулеры не заблокированы в `robots.txt`; перед запуском сверить актуальные user-agent и назначение токенов с официальной документацией каждого провайдера
- [ ] Признаки E-E-A-T: автор с реальной биографией, дата публикации и обновления, контакты, юридические страницы
- [ ] Контент доступен без JavaScript: серверный рендер или статический HTML, а не пустой `<div id="root">`

## 4. Честный замер после деплоя

Балл GEO-аудита не равен цитируемости. Страница может набирать 79/100 при нуле упоминаний в нейросетях. Поэтому:

- [ ] Задать 5–10 живых запросов в ChatGPT, Perplexity и Gemini на языке ЦА: «лучший X для Y», «как выбрать X», «X vs конкурент»
- [ ] Зафиксировать, упоминается ли бренд и какие источники цитируются вместо него
- [ ] Повторить через 2–4 недели после публикации
- [ ] Каждую цифру в отчёте проверять у первоисточника: поисковики выдумывают статистику

## 5. Мультиязычность (только после утверждения финальной версии)

Пайплайн использует один HTML на страницу: **главный язык лежит в HTML и индексируется поисковиками**, остальные языки подключаются JS-переключателем только для людей (см. `multilingual-single-file.md`). Поэтому:

- [ ] Главный язык выбран по рынку, на котором нужен поисковый трафик; `<html lang>` соответствует ему
- [ ] Title, description, schema.org и первый абзац написаны на главном языке
- [ ] hreflang НЕ ставится: у страницы один URL. Если нужен поисковый трафик на двух и более языках — это отдельные URL (`/en/`, `/ru/`) с hreflang и `x-default`, такой вариант выходит за рамки пайплайна и делается отдельно
- [ ] Бренд и слоганы не переводятся дословно, адаптируется смысл
- [ ] Primary барьер и hero-обещание адаптированы под культурный контекст региона

## 6. Аналитика и согласие

- [ ] GTM-контейнер, пиксели через триггер Window Loaded, не инлайном
- [ ] Consent/opt-out реализованы по требованиям конкретного региона: для EU/UK несущественные cookies обычно блокируются до согласия; для California отдельно проверены disclosure, opt-out sale/share и Global Privacy Control
- [ ] Ключевое событие (клик по CTA, отправка формы) проверено по телу запроса в живом браузере
- [ ] UTM только на входящих внешних ссылках
