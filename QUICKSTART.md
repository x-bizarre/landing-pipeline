# Быстрый старт

## Вариант 1 — Claude Code

Требования: установленный Git и Claude Code, доступ к веб-поиску для Шага 2, современный браузер для визуальной проверки.

```bash
git clone https://github.com/x-bizarre/landing-pipeline.git
cd landing-pipeline
./install.sh --dry-run
./install.sh
```

Если одноимённые скиллы уже установлены, скрипт остановится. Для обновления с резервной копией:

```bash
./install.sh --force
```

Затем открой папку будущего лендинга в Claude Code и вызови `/landing-pipeline`. На каждом чекпоинте проверяй артефакт перед продолжением.

## Вариант 2 — чат с LLM

1. Скопируй `00-orchestrator/ORCHESTRATOR-RU.md` в новый чат.
2. Скажи, какая это платформа и умеет ли она искать в интернете и создавать файлы/Canvas.
3. На Шаге 5 прикрепи пять CSV из `05-design/data/`.
4. Сохраняй результаты под именами, которые указывает оркестратор.

Без веб-доступа Шаг 2 нельзя считать исследованием: либо приложи отзывы с URL вручную, либо пропусти шаг и пометь дальнейшие выводы как гипотезы.

## Что пайплайн не гарантирует

- Конверсию, лиды, позиции в поиске или цитирование AI-системами.
- Конкретный Lighthouse score до проверки реального деплоя.
- Юридическую корректность автоматически созданных документов.
- Истинность синтетических персон. Это генератор гипотез, не замена живым интервью.

## Проверка репозитория

```bash
python3 scripts/check_repo.py
```

Проверка ловит сломанные внутренние ссылки, конфликтующие имена артефактов, невалидный frontmatter скиллов и типовые следы секретов в текущих файлах. Она не заменяет отдельный аудит истории Git.

Для короткой поведенческой проверки после установки используй обезличенный сценарий из `examples/smoke-test-prompt.md`.
