# data — база дизайна для Шага 5

Копия данных из [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) (MIT, © Next Level Builder). Лежит здесь, чтобы Шаг 5 работал без установки скилла: в Claude Code модель читает файлы напрямую, в браузерном чате пользователь прикрепляет их в начале Шага 5.

| Файл | Строк | Что внутри |
|---|---|---|
| `styles.csv` | 88 | Стили: ключевые слова, цвета, типографика, эффекты, для чего подходит и не подходит |
| `colors.csv` | 192 | Палитры по типу продукта: primary / secondary / accent / фон / текст |
| `typography.csv` | 74 | Пары шрифтов с Google Fonts URL и настройкой Tailwind |
| `landing.csv` | 34 | Landing patterns: порядок секций, место CTA, цветовая стратегия, эффекты |
| `ux-guidelines.csv` | 119 | UX-правила: доступность, касания, производительность, адаптив |

Обновить до свежей версии: скачать те же файлы из `src/ui-ux-pro-max/data/` исходного репозитория.
