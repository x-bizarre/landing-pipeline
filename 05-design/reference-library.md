# Reference Library — каталог «недефолтного» дизайна

> Этот файл — источник правды для ухода от «вида, сделанного через AI».
> Когда пользователь просит сделать/переделать
> сайт или лендинг — НЕ выдумывать стиль из головы и НЕ предлагать общие
> «минимализм / glassmorphism». Сначала прийти СЮДА, выбрать конкретную
> дизайн-систему-эталон и конкретные элементы-эффекты, потом миксовать.

---

## ЧАСТЬ 1. Источники (что где брать)

### A. Дизайн-системы реальных сайтов — ЗА ОСНОВУ (стиль, цвет, шрифты, ритм)

**Refero Styles** — https://styles.refero.design/
- 2000+ дизайн-систем реальных топовых продуктов (Apple, Linear, Vercel, Mercury,
  Stripe, Calendly, Family.co, Arc, Raycast и т.д.).
- У каждого есть машиночитаемый `DESIGN.md` (цвета, типографика, отступы).
- КАК ИСПОЛЬЗОВАТЬ: открываю нужный сайт-эталон → беру его DESIGN.md → задаю Claude
  «делай в дизайн-системе как <X>, вот её цвета/шрифты/ритм». Это и убивает дефолт:
  страница начинает выглядеть как конкретный дорогой продукт, а не как «AI-editorial».
- Это НЕ код компонентов. Это насмотренность + параметры стиля.

### B. Библиотеки готовых эффектов — ДЛЯ ДЕТАЛЕЙ (анимации, фоны, секции)

**React Bits** — https://www.reactbits.dev/  (⭐ основная, бесплатная, open-source)
- Есть pro-версия — https://pro.reactbits.dev/ — расширенные компоненты за деньги; по умолчанию хватает бесплатных, платное не обещать.
- 4 категории: Text Animations, Backgrounds, Animations, Components.
- Каждый компонент в 4 вариантах: JS/TS × CSS/Tailwind — подходит под любой стек.
- Лицензия свободная, код твой. Это первый источник эффектов по умолчанию.
- Чем брать: живые фоны, анимация текста, появление по скроллу, hover-эффекты.

**Aceternity UI** — https://ui.aceternity.com/  (самые «вау»-эффекты)
- React + Tailwind + Framer Motion.
- Aurora-фоны, метеоры, 3D-карточки, Google Gemini effect, Background Beams,
  Evervault card, Sticky Scroll Reveal, Bento Grid, Floating Navbar/Dock.
- ⚠️ Часть бесплатна, полный доступ — подписка. Бесплатных хватает. Не обещать платное.

**Fancy Components** — https://www.fancycomponents.dev/  (редкие/дизайнерские эффекты)
- React + Framer Motion, open-source.
- Физика (гравитация, упругие линии), gooey/pixelate SVG-фильтры, scramble-текст,
  typewriter, текст вдоль SVG-пути, и главное — **Stacking Cards** (карточки наезжают
  друг на друга по скроллу). Самое «не-дефолтное», когда нужно удивить.

**21st.dev** — https://21st.dev/community/components  (маркетплейс компонентов)
- Community-компоненты: герои, прайсинги, навигации, футеры, модалки, таблицы.
- Есть MCP-интеграция (можно подключить, чтобы Claude тянул компоненты напрямую).
- Брать, когда нужен готовый блок целиком (например, нестандартный pricing).

### C. НЕ использовать как движок (только подсмотреть)

**Aura.build** — https://www.aura.build/
- Отдельный AI-билдер сайтов (конкурент Claude Code), freemium.
- Мы работаем в Claude Code (или другом LLM-агенте) осознанно. Отдельный билдер не заводим.
- Можно лишь подсмотреть их шаблоны для вдохновения — но для этого лучше Refero.


### Правило долговечности источников
Библиотеки и каталоги со временем меняются, переезжают и закрываются. Порядок действий:
1. Ссылка не открывается или структура сайта другая → не останавливаться: поискать в интернете актуальный адрес или живой аналог того же класса («библиотека готовых UI-эффектов», «каталог дизайн-систем реальных продуктов»).
2. Главное в этом файле — не ссылки, а принципы: эталон из реального продукта → дозировка эффектов → анти-дефолт чек. Они работают с любым источником.
3. Нашёлся стабильно лучший новый источник → добавить сюда одной строкой; мёртвый → пометить, принципы не трогать.

## ЧАСТЬ 2. Карта «тип проекта → эталон → эффекты → дозировка»

Когда определён тип проекта, отсюда беру стартовую связку. Это НЕ жёсткий закон —
это набор сильных, проверенно «недефолтных» направлений, которые предлагаются пользователю
на выбор (пользователь может не быть дизайнером, поэтому варианты идут с именами эталонов).

| Тип проекта | Эталоны из Refero (за основу) | Эффекты-кандидаты | Дозировка |
|-------------|-------------------------------|-------------------|-----------|
| **B2B / SaaS / агентство**  | Linear, Vercel, Mercury, Stripe | Aurora-фон в hero (Aceternity), scroll-reveal текста (React Bits), Bento-grid фич | Сдержанно: 1-2 эффекта, упор на чистоту и ритм |
| **Личный бренд** (портфолио) | Family.co, Rauno/Raycast, Arc, Igloo | 3d-letter-swap или scramble в имени (Fancy/React Bits), stacking-cards для проектов, живой градиент-фон | Ярче: можно 3-4 заметных эффекта, личность важнее строгости |
| **Продукт-история / эмоция**  | Airbnb, Headspace, тёплые editorial | Мягкое появление по скроллу, параллакс фото, плавные градиенты. БЕЗ агрессивной анимации (тон бренда — спокойный) | Сдержанно-тёплая: эмоция через типографику и фото, не через «вау» |
| **Игры / фан**  | смелые бренды, brutalism, bold-color | Физика (Fancy), gooey-фильтры, крупная анимированная типографика, интерактивные фоны | Отрыв: можно перегружать, это часть вайба |
| **Фриланс-лендинг клиента**  | под нишу клиента, но всегда выше «дефолта» | 1 сильный hero-эффект + аккуратные scroll-появления | Сдержанно по умолчанию, ярче если ниша креативная |

### Принцип дозировки (общий)
- **Hero** — место для ОДНОГО сильного эффекта (живой фон ИЛИ анимация заголовка, не всё сразу).
- **Секции** — плавные появления по скроллу (reveal), но без салюта на каждом блоке.
- **Остальное** — чистая типографика, воздух, ритм отступов. Дороговизна = сдержанность + 1-2 точки удивления.
- Игры — исключение, там перегруз уместен.

## ЧАСТЬ 3. Как я работаю с этим (обязательный порядок)

1. **Определяю тип проекта** (см. таблицу). Если непонятно — спрашиваю пользователя.
2. **Иду в Часть 2**, беру 2-3 эталона-направления ПОД ТИП. НЕ выдумываю «минимализм».
3. **Показываю пользователю выбор** именами реальных эталонов + что за эффекты, например:
   - «A — как **Linear**: холодный, чёткий, aurora-фон в hero, текст проявляется по скроллу»
   - «B — как **Family.co**: тёплый, крупная типографика, карточки-стопкой, живой градиент»
   - «C — как **Vercel**: контраст чёрное/белое, Bento-сетка фич, минимум цвета»
   Под каждым — одна строка «что это даёт». Это решает боль пользователя: она видит НЕ-дефолтные
   варианты, которых сама не знает, с понятными референсами.
4. **После выбора** — тяну реальные DESIGN.md из Refero и реальные компоненты из библиотек,
   собираю и миксую по дозировке из таблицы. По возможности даю пользователю команду открыть
   нужную страницу Refero/библиотеки, чтобы она видела эталон глазами.
5. **Дозирую эффекты** по типу проекта (Часть 2). Не вешаю всё подряд.

### Готовые фразы-промпты для сборки (примеры)
- «Возьми DESIGN.md сайта Linear из Refero и примени его палитру, шрифты и ритм отступов к этому лендингу.»
- «Добавь в hero компонент Aurora Background из Aceternity UI (React+Tailwind+Framer Motion).»
- «Сделай секцию фич как Stacking Cards из Fancy Components — карточки наезжают по скроллу.»
- «Заголовок оживи через 3D Letter Swap из React Bits, вариант Tailwind.»
- «Текст в секциях пусть проявляется по скроллу — Scroll Reveal из React Bits.»

### Анти-дефолт чек (перед показом результата)
- [ ] Я взял конкретный эталон из Refero, а не абстрактный стиль из головы?
- [ ] В hero есть ровно один сильный эффект, а не каша?
- [ ] Эффекты дозированы по типу проекта (B2B сдержанно / личное ярче / игры отрыв)?
- [ ] Это не похоже на дефолтный AI-editorial (одинаковый светлый фон, центрированный текст, серые карточки)?
- [ ] Стек эффектов совпадает со стеком сайта (или дал HTML/Tailwind-вариант)?
