# PIPELINE — шаги, входы, выходы, инструменты

Продолжительность прогона зависит от веб-доступа, исходных данных и стека. Каждый шаг заканчивается артефактом-файлом в папке проекта (`project-template/`) и отметкой в `STATUS.md`. Модель не пересказывает содержимое предыдущих шагов, а ссылается на него по названию секции.

## 5 ролей внутри одного LLM

| Роль | Шаги | За что отвечает |
|---|---|---|
| Research Director | 0, 1, 2, 3 | Данные о продукте, проверяемые голоса рынка и явно помеченные гипотезы по сегментам |
| Copy Lead | 4 | Copy Brief: Hero, тон голоса, value props, возражения, CTA |
| Design Director | 5 | Контрастные дизайн-направления из базы, hero-макеты, design-tokens |
| Landing Generator | 6 | Landing pattern, стек, код лендинга, legal-документы |
| Polish Layer | 7 | SEO/GEO, мобильная версия, PageSpeed, мультиязычность |

## Что решено и не обсуждается внутри пайплайна

- **Синтетический кастдев ограничен объёмом вебинара:** сегменты и четыре вопроса — workflow и боль, существующие решения, желаемое решение и готовность платить, где ищут такой софт. Дополнительные блоки не добавляются.
- **Парсинг отзывов — best-effort по доступным источникам.** Пайплайн фиксирует покрытие и пробелы и не называет выборку насыщенной, стабильной или репрезентативной.
- **Primary сегмент выбирает пользователь**, модель обосновывает primary барьер и мотив.
- **Стили только из базы.** В Claude Code модель читает `05-design/data/*.csv`; в чате просит прикрепить их. Выбор без базы помечается `[без базы]`.
- **Количество hero-вариантов выбирает пользователь**: 1, 3 или 5. Контрастность по трём осям: температура / энергия / эпоха.
- **Стек выбирает модель** без вопроса, объясняя выбор в две строки: HTML + Tailwind по умолчанию, Next.js + shadcn/ui для интерактива, Astro + MDX для блога, Framer / Webflow для no-code. Раздел «Код и структура файлов» в LANDING-RULES написан для HTML-трека.
- **Fakedoor — не отдельная ветка.** Лендинг для проверки гипотезы такой же полноценный, отличается только social proof (`[FILL: waitlist]`).
- **Legal-документы генерируются по региону** из шага 1 с предупреждением показать юристу для чувствительных данных.
- **PageSpeed — ручной путь**: пользователь деплоит, прогоняет pagespeed.web.dev и копирует отчёт в чат. Технические фиксы применяются сразу, визуальные — через вопрос.
- **Мультиязычность последней и в одном файле.** Главный язык (SEO) остаётся в HTML и индексируется, остальные языки — JS-переключатель для людей, без hreflang. Поисковый трафик на нескольких языках сразу — отдельная задача с отдельными URL, вне пайплайна.
- **Память проекта — файлы, не внешний трекер.** `STATUS.md` + артефакты в папке проекта. Никаких обязательных сервисов.

## Как блоки связаны данными

```
discovery-brief ──┬──► reviews-synthesis ──► custdev-hypotheses ──► copy-brief ──┬──► hero-variants ──► design-tokens
                  │                                                             │
                  └─────────────────────────────────────────────────────────────┴──► landing.html ──► seo/mobile patches ──► pagespeed ──► multilingual
```

Шаг 2 можно пропустить осознанно: тогда все пункты шага 3 остаются непроверенными гипотезами. Модель об этом предупреждает и не создаёт реальных цитат или подтверждений.

## Формат артефактов по платформам

Claude → Artifacts, ChatGPT и Gemini → Canvas, Perplexity и остальные → в чат с предупреждением «большой блок, сохрани в файл и открой новый чат для следующего шага». Платформа спрашивается самым первым вопросом шага 1. Итоговое место любого артефакта — файл в папке проекта.
